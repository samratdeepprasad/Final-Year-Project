# AI Learning Adventure

A simple, Duolingo-style web app to learn basic concepts of Artificial Intelligence through quick multiple-choice questions.

## Running locally

Open `index.html` in your browser. No build step or server is required. Progress is shown with a dynamic bar, and you can restart to improve your score.
